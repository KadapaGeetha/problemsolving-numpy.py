# NumPy Practice – 20 Questions

## About This Repository
This repository contains my hands-on practice of NumPy, a Python library used for numerical computing and data analysis.

I completed 20 practical questions covering array creation, manipulation, indexing, slicing, iteration, and real-world data analysis scenarios.

- 0D, 1D, 2D and 3D arrays
- `np.arange()` and `np.linspace()`
- `np.zeros()`, `np.ones()` and `np.full()`
- Random number generation
- `np.logspace()`

### 2. Data Types & Array Properties
- Data type conversion using `astype()`
- `shape`, `size`, `ndim` and `dtype`
- `itemsize` and `nbytes`

### 3. Indexing & Slicing
- Positive and negative indexing
- 2D array indexing
- 1D and 2D slicing
- 3D array slicing

### 4. Fancy Indexing & Boolean Masking
- Fancy indexing
- Boolean conditions and filtering
- Student marks analysis

### 5. Iteration & Real-World Applications
- `np.nditer()`
- `np.ndenumerate()`
- Sales data analysis
- Employee salary analysis
